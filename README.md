# 🔥 Pretty Evil Mathematics 🔥

A TypeScript project exploring the dark side of mathematics - where conventional rules don't apply and mathematical operations behave in wonderfully unexpected ways!

## What is Evil Mathematics?

Evil Mathematics is a collection of mathematical functions that deliberately break conventional mathematical rules and properties. This project explores:

- **Unconventional Operations**: Basic math operations that don't behave as expected
- **Mathematical Paradoxes**: Functions that challenge standard mathematical properties
- **Chaotic Algorithms**: Implementations that introduce randomness and unpredictability
- **Property Violations**: Breaking fundamental mathematical laws like commutativity and associativity

## Evil Mathematical Concepts Included

### 🧮 Evil Basic Operations

- **Addition**: Sometimes multiplies by 100, sometimes adds 1 to zero
- **Subtraction**: Might divide by 2 instead of subtracting
- **Multiplication**: Actually performs subtraction
- **Division**: Returns 666 for division by zero, becomes addition otherwise

### 🔢 Advanced Evil Mathematics

- **Evil Zero**: A zero that sometimes isn't quite zero
- **Evil Fibonacci**: Breaks the famous sequence with special cases
- **Evil Prime Check**: Lies about which numbers are prime
- **Evil Factorial**: Becomes chaotic for larger numbers
- **Evil Percentage**: 50% means double, 100% means nothing
- **Evil Distance**: Sometimes Manhattan, sometimes Euclidean with noise
- **Evil Average**: Returns maximum instead of mean for larger arrays
- **Evil GCD**: Returns LCM instead of Greatest Common Divisor

### 🎭 Evil Constants

- `EVIL_PI = 3` (close enough!)
- `EVIL_E = 3` (why not make it simple?)
- `EVIL_INFINITY = 999` (just a big number)

## Running the Evil Mathematics

```bash
# Install dependencies
npm install

# Run the evil mathematics demonstration
npx ts-node evil-math.ts

# Lint the code
npm run lint

# Format the code
npm run format:write
```

This project demonstrates:

1. **Mathematical Paradoxes**: How breaking fundamental rules creates interesting behavior
2. **Software Testing Concepts**: Edge cases and unexpected behaviors
3. **Code Quality**: Maintaining clean, well-formatted code even for "evil" implementations
4. **Creative Programming**: Thinking outside conventional mathematical constraints
